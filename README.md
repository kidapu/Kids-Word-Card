# こどもアプリ

未就学児向けの、ことば・かず・いろ・もじで遊ぶ小さなアプリを集めたもの。
市販の「音の出るカード」玩具のデジタル版から始まって、
いまは指でなぞって遊ぶものも入っています。

文字が読めない子どもが、ひとりで触って遊べることを目指しています。
広告も課金もなく、ネットにつながっていなくても動きます。

## あそびかた

**https://kidapu.github.io/Kids-Word-Card/**

トップにアプリが並んでいるので、そこから選びます。
iPad の Safari で開いて、ホーム画面に追加して使うのがおすすめです。

カードで遊ぶ 4 つには、**ずかん**（眺めて、押すと音が鳴る）と
**クイズ**（音を聞いて、3 つから選ぶ）の 2 つの遊び方があります。
めいろとなぞりカードは、指で動かして遊びます。

# カードで あそぶ

## 🍎 おしゃべりカード

ことばのカードが 88 枚。どうぶつ・たべもの・のりもの・しぜん・みのまわりの
5 つのなかまに分かれていて、なかまごとに色がついています。

**ずかん** — カードを押すと、英語と日本語を続けて読みます。
押している間はその絵がゆれます。下までスクロールしても終わりが来ず、
いくらでも眺められます。**🔀** で順番を混ぜ、**🗂** でなかまごとの並びに戻ります。

**クイズ** — 音が流れて、3 枚から選びます。
正解するとピンポンと紙吹雪が出て、英語と日本語の両方で答えを教えてくれます。
間違えたらブーと鳴って、押したカードが何だったかを読んでくれます。

## 🔢 かずカード

1 から 10 まで。

**ずかん** — 数字が並びます。押すとその数を読みます。
数字の下には同じ数だけ丸が並んでいるので、「いくつ分か」が目でも分かります。

**クイズ** — 絵がいくつか並んで「これは いくつ？」と聞かれます。3 つの数字から選びます。
正解するとピンポンと紙吹雪が出て、英語と日本語の両方で数を教えてくれます。
間違えたらブーと鳴って、押した数を読みます。

## 🎨 いろカード

12 色。あか・オレンジ・きいろ・みどり・みずいろ・あお・むらさき・ピンク・
ちゃいろ・くろ・しろ・にじいろ。にじいろのカードは虹のグラデーションです。

**ずかん** — 色がそのままカードになって並びます。押すと英語と日本語で名前を続けて読みます。

**クイズ** — 色の名前が読まれて、3 つの色から選びます。
カードには名前を出さないので、色だけを見て選びます。

## 🔤 もじカード

アルファベット 26 字と、ひらがな 46 字。

**ずかん** — 五十音表・アルファベット表が出ます。押すとその文字を読みます。
**🔀** で順番を混ぜ、**🗂** で表の並びに戻ります。

**クイズ** — 文字が読まれて、3 つから選びます。
正解するとピンポンと紙吹雪、間違えたらブーと鳴って、押した文字を読みます。

# ゆびで あそぶ

## 🐰 めいろ

スタート（🐰）からゴール（🥕）まで、かべに当たらないように指でなぞります。
なぞったところには、うさぎの足あとが左右かわりばんこに付いていきます。

最初の面はかべがありません。まっすぐ引けばクリアです。
1 面ごとにかべが 1 本ずつ増えて、5 本まで。そのあとは穴が少しずつ狭くなります。
穴は必ず通れる場所に開くので、解けない面は出てきません。

かべに当たるとブーと鳴って足あとが消え、やり直しになります。
ゴールに着くとピンポンと紙吹雪が出て、うさぎがなぞった道を走っていき、次の面へ進みます。

## ✏️ なぞりカード

薄く出たもじを、指でなぞって塗ります。ひらがな 46 字とアルファベット 26 字。

**筆順は問いません。** 何度なぞってもよくて、下のバーが目印まで伸びたら次のもじへ進みます。
やり直したいときは **🧽 けす** を押します。

画面をぜんぶ塗りつぶしてもクリアにはなりません
（線がもじの上に乗っているかも見ているためです）。

---

## ABC / あいう の きりかえ

めいろ以外のアプリには、左上に **ABC / あいう** の切り替えがあります。
意味はアプリによって変わります。

| アプリ | 切り替わるもの |
| --- | --- |
| おしゃべりカード | 先に鳴らすことば（**あいう** にすると日本語が主になり、カードの大きい文字も、読む順番も、クイズの出題も日本語が先に）|
| かずカード | 英語で数えるか、日本語で数えるか |
| いろカード | 先に鳴らすことば |
| もじカード | アルファベットか、ひらがなか |
| なぞりカード | ひらがなか、アルファベットか |

めいろにはありません（ことばを使わないため）。

## そのほか

- 絵柄はいまのところ絵文字です。
- 音声は端末の読み上げ機能を使っています（今後、録音した音声に差し替える予定）。
